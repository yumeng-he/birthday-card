# 🎂 A Pastel Interactive Birthday Card

A small interactive birthday card website with a soft pastel design, simple animations, and a downloadable card.

🌐 **Live Demo:**  
https://yumeng-he.github.io/birthday-card/

## ✨ Features

- Enter a birthday person's name
- Interactive transition from the welcome screen to the birthday card
- Random pastel card styles
- Floating balloons, ribbons, and sparkles
- English and Chinese language support
- Responsive design for desktop and mobile
- Save the birthday card as a PNG image
- Back button to return to the welcome screen

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- [html2canvas](https://html2canvas.hertzen.com/) for saving the card as an image

## 📸 How It Works

1. Choose a language: English or 中文
2. Enter the birthday person's name
3. Click **Open the Card**
4. A personalized birthday card is generated with a randomized pastel style
5. Save the card as a PNG image or go back and create another one
